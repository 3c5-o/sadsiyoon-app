# سادسيون — Sadsiyoon (Android Native)

نسخة Android تجريبية عربية **بدون WebView وبدون حسابات أو قاعدة بيانات**.

## محتوى التجربة
- 40 محاضرة بالترتيب الظاهر في الفصل الأول «الأعداد المركبة» للأستاذ حيدر عبدالائمة (دفعة 2026).
- أسماء المحاضرات الكاملة محفوظة في `LessonCatalog.java`.
- HLS Media3 ExoPlayer الأصلي مع تقديم/إرجاع/تنقل التالي والسابق وتغيير السرعة والتدوير وPiP.
- بحث بالعناوين، حفظ المفضلة وعلامة الإكمال وآخر موضع مشاهدة محلياً باستخدام SharedPreferences.
- زر منفصل يفتح رابط `?player=1` في المتصفح. **المشغّل الداخلي يستخدم ملف `.m3u8` بدون هذا المعامل**.
- لا يتم نسخ ملفات فيديو أو تنزيلها أو إعادة استضافتها.

> **تنبيه حقوق المحتوى:** روابط المصادر مرتبطة بمحتوى جهات أخرى. هذا نموذج تقني للاختبار، ويجب الحصول على إذن أصحاب الحقوق قبل توزيعه مع محاضراتهم. صلاحية الروابط الخارجية وتشغيلها غير مضمونين.

## بناء APK

1. افتح تبويب **Actions** في المستودع.
2. افتح **Build Sadsiyoon APK** ثم **Run workflow** (أو راقب البناء التلقائي مع كل Push).
3. عند نجاح البناء ستجد ملف APK داخل **Artifacts → sadsiyoon-debug-apk**.
4. هذه نسخة **debug** للتجربة فقط. توقيعها قد يختلف بين تشغيل وآخر؛ تحديثات الإنتاج تحتاج مفتاح توقيع خاص محفوظاً خارج المستودع.

### إعدادات البناء
- Android Gradle Plugin: 8.13.2
- Gradle: 8.13
- Java: 17
- compileSdk: 36
- minSdk: 26
- targetSdk: 35
- Media3: 1.11.1

لا تحتوي النسخة على أي مفاتيح API أو خدمات Firebase/Supabase/OneSignal.

## هيكل المشروع
```
app/src/main/java/com/sadsiyoon/app/
  MainActivity.java    واجهة الفصل والبحث والقائمة
  PlayerActivity.java  تشغيل HLS ومزايا التحكم
  LessonCatalog.java   بيانات المحاضرات
  Ui.java              تصميم الواجهة
.github/workflows/android-debug.yml
```
